# Claude Code 3D

ดูว่า Claude Code กำลังทำอะไรอยู่ผ่านฉาก 3D แบบสดๆ หัวหน้าทีมเดินจ่ายงานให้ผู้สอดแนม นักพัฒนา ผู้ทดสอบ และผู้สรุป พร้อมตัวจับเวลาและตัวนับ token ด้านล่าง

ทำงานในเครื่องเท่านั้น ดูอย่างเดียว ไม่มีข้อมูลออกจากเครื่องคุณ

สร้างโดย kob ai

มีสามธีมให้เลือกจากกล่อง **Theme**: ห้องโถงซามูไร ออฟฟิศธรรมดา และเถียงนาอีสานยุคเก่า

[English](README.md)

## ที่ต้องมี

- Claude Code ที่รองรับ plugin (ทดสอบกับ CLI; ส่วนขยาย VS Code ใช้ plugin ร่วมกับ CLI แต่ยังไม่ได้ทดสอบ)
- Node.js 18 ขึ้นไปใน `PATH`
- เบราว์เซอร์ที่รองรับ WebGL

## ติดตั้ง

ใน Claude Code พิมพ์:

```
/plugin marketplace add thekaroe-thailand/claude-code-3d
/plugin install claude-code-3d@claude-code-3d
```

จากนั้นสั่ง `/reload-plugins` หรือเปิด session ใหม่

## ใช้งาน

เปิดฉากด้วย:

```
/claude-code-3d:office
```

ตัวเลือก: `--theme=samurai`, `--theme=office`, `--theme=isan`, `--no-open` (แค่แสดงที่อยู่ ไม่เปิดเบราว์เซอร์)

หรือเปิด `http://127.0.0.1:3737/` เอง ถ้าพอร์ตนี้ไม่ว่าง server จะเลือกพอร์ตอื่น ดูที่อยู่ได้ใน `~/.claude-code-3d/server.json`

server เบื้องหลังเริ่มเองเมื่อ hook ทำงานครั้งแรก ใช้ร่วมกันทุก session บนเครื่อง และปิดเองเมื่อไม่มีกิจกรรมและไม่มีหน้าเปิดอยู่นาน 1 ชั่วโมง

## สิ่งที่เห็น

| ใคร | ทำอะไร |
|---|---|
| **SA** (ผู้สอดแนม) | `Read`, `Grep`, `Glob`, ค้น/ดึงเว็บ, tool ของ MCP และ subagent ประเภทสำรวจ/วางแผน |
| **Dev** (นักพัฒนา) | `Edit`, `Write`, คำสั่ง shell อื่นๆ และ subagent ทั่วไป |
| **Tester** | คำสั่ง shell ที่เป็นการรัน test, build, lint, type-check และ subagent ประเภทรีวิว |
| **Summary** | เขียนคำตอบสุดท้ายเมื่อจบรอบ |

- พรอมต์ใหม่ = งานใหม่: จับเวลาเริ่มใหม่ และผู้สอดแนม "อ่านโจทย์"
- ระหว่างที่ Claude กำลังคิดและไม่มี tool ทำงาน ผู้สอดแนมจะขึ้น **Thinking** ฉากจะได้ไม่ดูนิ่งในช่วงที่ยาวที่สุดของรอบ
- หัวหน้าเดินไปหาคนที่เพิ่งได้งานแล้วยื่นม้วนคำสั่ง กรอบคำพูดบอกชื่อ tool และรายละเอียดสั้นๆ (ชื่อไฟล์ คำสั่ง pattern)
- **Token** นับต่อหนึ่งงานจาก transcript ของ session โดยนับแต่ละข้อความครั้งเดียว วางเมาส์บนตัวเลขเพื่อดูรายละเอียดแคช ถ้าอ่าน transcript ไม่ได้จะแสดง `—`
- รัน Claude Code หลาย session พร้อมกันได้ เมื่อมีมากกว่าหนึ่งจะมีกล่อง **Session** ให้เลือก ไม่ปนกัน "Latest" คือ session ที่ขยับล่าสุด
- ลากเมาส์เพื่อหมุนกล้อง เลื่อนล้อเพื่อซูม ดับเบิลคลิกเพื่อรีเซ็ตมุม

## ความเป็นส่วนตัว

- ทุกอย่างอยู่ที่ `127.0.0.1` ไม่มีบัญชี ไม่มี analytics ไม่มีการเรียกเครือข่ายภายนอก
- สคริปต์ hook ส่งต่อเฉพาะ: ชื่อ event, session id, ที่อยู่ transcript, โฟลเดอร์ทำงาน, ชื่อ tool, ประเภท agent และฟิลด์สั้นๆ ของ tool input (คำสั่ง พาธไฟล์ pattern URL คำค้น) ข้อความถูกตัดที่ 300 ตัวอักษร และ server เก็บแบบสั้นกว่านั้น: พาธไฟล์เหลือสองส่วนท้าย คำสั่งเหลือ 120 ตัวอักษรแรก
- **ไม่ส่งต่อและไม่เก็บพรอมต์ เนื้อหาไฟล์ หรือผลลัพธ์ของ tool**
- หน้าจอแสดงคำสั่งและชื่อไฟล์ ถ้าเรื่องนี้สำคัญ อย่าเปิดทิ้งไว้บนจอที่คนอื่นเห็น
- server อ่านเฉพาะ transcript ที่อยู่ในโฟลเดอร์ตั้งค่าของ Claude และใช้เพื่อรวม token เท่านั้น
- ปฏิเสธคำขอจากเว็บอื่นและชื่อโฮสต์อื่น (ตรวจ Origin และ Host) เว็บไซต์จึงอ่านหรือป้อนข้อมูลให้ไม่ได้
- ผู้ใช้อื่นบนเครื่องเดียวกันเข้าถึง `127.0.0.1` ได้ ถ้าใช้เครื่องร่วมกัน ให้ถือว่าฉากนี้ผู้ใช้อื่นอาจเห็น

## แก้ปัญหา

- **ไม่มีอะไรขยับ** ตรวจว่า `node --version` ได้ 18 ขึ้นไป รัน session โดยตั้ง `C3D_DEBUG=1` แล้วอ่าน `~/.claude-code-3d/hook.log`
- **ดูว่า server ได้รับอะไร** เปิด `http://127.0.0.1:3737/debug/events` จะเห็น 200 event ล่าสุด (เฉพาะชื่อ ไม่มีพาธหรือพรอมต์) และจะมี event เฉพาะ session ของ Claude Code ที่เริ่มหลังติดตั้ง plugin เท่านั้น ให้เปิดแชทหรือ session ใหม่ก่อน
- **ไม่รู้จัก `/claude-code-3d:office`** สั่ง reload plugins หรือเปิด session ใหม่ Claude Code ใส่ชื่อ plugin นำหน้าเสมอ ใช้ `/office` เฉยๆ ไม่ได้
- **"This site can't be reached"** server ไม่ได้รันอยู่ สั่ง `/claude-code-3d:office` หรือพิมพ์อะไรใน Claude Code ก็จะเริ่มเอง บุ๊กมาร์กใช้ได้เฉพาะตอน server ทำงานอยู่
- **ตัวละครค้างที่ "working"** จะถูกปล่อยเมื่อจบรอบ หรือเมื่อไม่มี event 10 นาที การกดขัดจังหวะกลางรอบอาจทำให้ค้างจนกว่าจะถึงตอนนั้น
- **หยุด server** ปิดเองเมื่อว่าง ถ้าจะหยุดทันที ให้จบ process id ที่เก็บใน `~/.claude-code-3d/server.json`
- **ถอนการติดตั้ง** `/plugin uninstall claude-code-3d@claude-code-3d` แล้วลบโฟลเดอร์ `~/.claude-code-3d`

## ควรรู้

- hook ทำงานแบบ async และจบด้วย exit 0 เสมอ จึงไม่ทำให้ session ช้าหรือพัง แต่แต่ละครั้งจะเริ่ม process Node สั้นๆ
- Claude Code มีเอกสารรูปแบบข้อมูลของ hook แต่บอกว่ารูปแบบ transcript เป็นของภายในและอาจเปลี่ยน การนับ token จึงเขียนแบบป้องกัน ถ้าเปลี่ยนจะแสดง `—` แทนที่จะพัง
- subagent ถูกจับคู่กับสี่บทบาทจากคำในชื่อประเภท/คำอธิบาย (เช่น "explore", "plan" ไปที่ผู้สอดแนม) ประเภทที่ไม่รู้จักไปที่ Dev
- ทดสอบบน Windows macOS และ Linux น่าจะใช้ได้แต่ยังไม่ได้ลอง

## พัฒนา

```
cd packages/core
npm test          # เทสต์หน่วยและเทสต์รวม
npm run demo      # session ปลอมที่เล่นวนซ้ำ เปิด http://127.0.0.1:3737/
```

ลอง plugin จากโฟลเดอร์ที่ clone มาโดยไม่ต้องติดตั้ง:

```
claude --plugin-dir .
claude plugin validate .
```

เพิ่มธีมใหม่: เขียนไฟล์ฉากใน `packages/core/public/` เพิ่มหนึ่งบรรทัดใน `public/themes.js` และจะเพิ่มบล็อก `[data-theme="..."]` ใน `style.css` ด้วยก็ได้ `npm run vendor` อัปเดตสำเนา three.js หลัง `npm install`
