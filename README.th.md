## 1. สรุปใน 60 วินาที

ต้องมี Claude Code, Node.js 18 ขึ้นไป และ git จากนั้นพิมพ์ในเทอร์มินัล:

```
claude plugin marketplace add thekaroe-thailand/claude-code-3d
claude plugin install claude-code-3d@claude-code-3d
```

แล้ว**เริ่มบทสนทนา Claude Code ใหม่** (plugin โหลดตอนเริ่มบทสนทนา) สั่ง Claude ให้ทำอะไรที่ใช้ tool เช่น "อ่านไฟล์ README.md แล้วสรุปให้หน่อย" แล้วเปิดที่อยู่นี้ในเบราว์เซอร์:

```
http://127.0.0.1:3737/
```

ตัวละครจะขยับเมื่อ Claude ทำงาน เท่านี้เลย ส่วนที่เหลือของหน้านี้อธิบายแต่ละขั้น สิ่งที่ควรเห็น และวิธีแก้เมื่อมีปัญหา

## 2. นี่คืออะไร (อธิบายแบบง่ายๆ)

เวลา Claude Code ทำงาน มันอ่านไฟล์ แก้ไฟล์ และรันคำสั่ง ปกติคุณเห็นแค่ข้อความที่เลื่อนผ่าน plugin นี้เปลี่ยนมันเป็นฉากเคลื่อนไหวเล็กๆ:

- งานแต่ละแบบมีตัวละครประจำ **SA** (ผู้สอดแนม) อ่านและค้นหา **Dev** (นักพัฒนา) แก้และเขียน **Tester** รันเทสต์และบิลด์ **Summary** เขียนคำตอบสุดท้าย
- **หัวหน้าทีม**เดินไปหาคนที่เพิ่งได้งาน ยื่นม้วนคำสั่ง และบอกว่างานคืออะไร
- **ตัวจับเวลา**บอกว่างานตอนนี้ใช้เวลาเท่าไร **ตัวนับ token** บอกว่า Claude ใช้ไปเท่าไรสำหรับงานนั้น

มัน**ดูได้อย่างเดียว** ไม่สามารถเปลี่ยนอะไร อนุมัติอะไร หรือสั่งอะไร Claude ได้ ไม่ใช้อินเทอร์เน็ต ไม่ต้องมีบัญชีหรือกุญแจ

ได้ข้อมูลมาจากไหน: Claude Code มีฟีเจอร์ชื่อ *hooks* คือโปรแกรมเล็กๆ ที่ Claude Code เรียกเมื่อมีเหตุการณ์เกิดขึ้น (tool เริ่ม tool จบ รอบจบ) plugin นี้ลงทะเบียนโปรแกรม hook ตัวเล็กหนึ่งตัว ซึ่งส่งคำอธิบายเหตุการณ์แบบย่อสั้นๆ ไปให้เว็บเซิร์ฟเวอร์เล็กๆ ที่รันบนคอมพิวเตอร์ของคุณเอง แล้วหน้าเว็บก็แสดงผล

## 3. ก่อนเริ่ม

ต้องมีทั้งหมดนี้ แต่ละบรรทัดบอกวิธีเช็ก

| ต้องมี | วิธีเช็ก | ถ้ายังไม่มี |
|---|---|---|
| **Claude Code** ล็อกอินและใช้งานได้ | `claude --version` แสดงเลขเวอร์ชัน (ทดสอบกับ 2.1.269) | ติดตั้งตามเอกสารทางการของ Claude Code |
| **Node.js 18 ขึ้นไป** | `node --version` ขึ้น `v18` หรือสูงกว่า | ติดตั้งรุ่น LTS จาก https://nodejs.org |
| **git** | `git --version` แสดงเลขเวอร์ชัน | ติดตั้งจาก https://git-scm.com (Claude Code ใช้ git ดาวน์โหลด plugin) |

**ระบบปฏิบัติการ:** ทดสอบบน Windows 11 ส่วน macOS และ Linux น่าจะใช้ได้ (โค้ดเรียกคำสั่ง "เปิดที่อยู่เว็บ" ปกติของแต่ละระบบ) แต่ยังไม่ได้ลอง ถ้าคุณลอง ช่วยเปิด issue บอกผลหน่อย

## 4. ติดตั้ง

มีสามวิธี เลือกตามที่คุณใช้ Claude Code

> **สำคัญสำหรับทุกวิธี:** hooks โหลดตอน**เริ่ม**บทสนทนา หลังติดตั้งให้เริ่มบทสนทนา**ใหม่** บทสนทนาเก่าที่เปิดค้างไว้ก่อนติดตั้งจะไม่ส่งข้อมูลเข้าฉาก

### วิธี A: เทอร์มินัล (ใช้ได้ทุกที่ และเป็นวิธีที่ทดสอบมากที่สุด)

เปิดเทอร์มินัลใดก็ได้ แล้วรัน:

```
claude plugin marketplace add thekaroe-thailand/claude-code-3d
claude plugin install claude-code-3d@claude-code-3d
```

ควรเห็นข้อความ "Successfully added marketplace" และ "Successfully installed plugin" ตรวจสอบ:

```
claude plugin list
```

ควรเห็น `claude-code-3d@claude-code-3d` เวอร์ชัน `Scope: user` และ `Status: enabled`

พิมพ์คำสั่งเดียวกันในเซสชันเทอร์มินัลของ Claude Code ก็ได้ เป็น `/plugin marketplace add ...` และ `/plugin install ...`

ค่าเริ่มต้นจะติดตั้งให้คุณใช้ในทุกโปรเจกต์ (ขอบเขต `user`) ถ้าต้องการจำกัด เพิ่ม `--scope project` หรือ `--scope local` ท้ายคำสั่งติดตั้ง

### วิธี B: ใช้ส่วนขยาย Claude Code ใน VS Code

**พิมพ์ `/plugin ...` ในช่องแชทของ VS Code ใช้ไม่ได้** มันตอบว่า "/plugin isn't available in this environment" ให้ใช้อย่างใดอย่างหนึ่งนี้แทน:

1. **แนะนำ:** เปิดเทอร์มินัลของ VS Code เอง (เมนู *Terminal → New Terminal*) แล้วรันสองคำสั่งจากวิธี A plugin และ marketplace ใช้ร่วมกันระหว่างเครื่องมือเทอร์มินัลกับส่วนขยาย VS Code จากนั้นกด `Ctrl+Shift+P` พิมพ์ `Reload Window` กด Enter แล้วเปิด**แชทใหม่**
2. หรือพิมพ์ `/plugins` (มี **s** ท้าย) ในช่องแชท ตามเอกสารของ Claude Code จะเปิดแผง "Manage plugins" ที่มีแท็บ Marketplaces (เพิ่ม `thekaroe-thailand/claude-code-3d`) และแท็บ Plugins (ติดตั้ง) เรายังไม่ได้ทดสอบแผงนี้เอง

### วิธี C: ลองก่อนโดยไม่ติดตั้ง

ดาวน์โหลดหรือ clone รีโปนี้ เปิดเทอร์มินัลในโฟลเดอร์ แล้วรัน:

```
claude --plugin-dir .
```

จะโหลด plugin เฉพาะเซสชันนั้น ปิดเซสชันแล้วไม่เหลืออะไรค้าง (ยกเว้นโฟลเดอร์เล็กๆ ที่อธิบายใน [หัวข้อ 9](#s9) ซึ่งเกิดขึ้นตอน server ของฉากทำงานอยู่)

### อยากดูฉากเฉยๆ โดยไม่ใช้ Claude Code เลย?

clone รีโปแล้วรัน demo ในตัว ซึ่งเล่นเหตุการณ์ปลอมวนซ้ำ:

```
cd packages/core
npm run demo
```

บน Windows ดับเบิลคลิก `start-demo.bat` ก็ได้ จะเปิด `http://127.0.0.1:3737/`

## 5. ทดสอบครั้งแรก (ทำครั้งเดียว)

ใช้เวลาราว 2 นาที และบอกได้ว่าทุกอย่างทำงานไหม

1. ตรวจว่าติดตั้ง plugin แล้ว (`claude plugin list`)
2. เริ่มบทสนทนา Claude Code **ใหม่** ในโฟลเดอร์ใดก็ได้ที่มีไฟล์ `README.md` (ไฟล์อะไรก็ได้)
3. วางหน้าต่างเบราว์เซอร์ไว้ข้างหน้าต่าง Claude Code ให้เห็นทั้งสองจอ
4. เปิด `http://127.0.0.1:3737/` ในเบราว์เซอร์ server เริ่มเองเมื่อบทสนทนาเริ่ม ถ้าขึ้นว่า "เข้าถึงไม่ได้" ให้ส่งข้อความในขั้นถัดไปก่อน แล้วรีเฟรชหน้า
5. ใน**ช่องแชทของ Claude** ส่งข้อความนี้:

   > รันคำสั่ง `node -e "setTimeout(()=>console.log('ok'),8000)"` ด้วย Bash แล้วอ่านไฟล์ README.md แล้วสรุปสามบรรทัด

สิ่งที่ควรเห็น:

| จังหวะ | ในฉาก |
|---|---|
| กด Enter | ตัวจับเวลาเริ่ม SA "อ่านโจทย์" |
| Claude เริ่มรันคำสั่ง | **Dev** ขึ้น "Working · Bash" หัวหน้าทีมเดินมาหา และมีกรอบคำพูดแสดงคำสั่ง |
| คำสั่งจบ Claude อ่านไฟล์ | **SA** ขึ้น "Working · Read" และหัวหน้าเดินไปหา SA |
| Claude กำลังคิดหรือเขียน | SA ขึ้น "Working · Thinking" |
| Claude ตอบเสร็จ | **Summary** เสร็จ (มีเครื่องหมายถูกสีเขียว) เวลาหยุด และตัวนับ token ขึ้นตัวเลข |

ข้อผิดพลาดที่เจอบ่อยที่สุดในขั้นนี้:

- พิมพ์คำสั่งในช่อง**เทอร์มินัล**เอง ฉากตอบสนองเฉพาะสิ่งที่ **Claude** ทำ ไม่ใช่คำสั่งที่คุณรันเอง
- ใช้บทสนทนาที่เปิดอยู่**ก่อน**ติดตั้ง ให้เริ่มบทสนทนาใหม่

ถ้าไม่ได้ผล ดู [แก้ปัญหา](#s8) วิธีเช็กเร็วที่สุดคือเปิด `http://127.0.0.1:3737/debug/events` หลังส่งข้อความ จะแสดง event ล่าสุดที่ server ได้รับ ถ้ามีแค่ `SessionStart` แปลว่าบทสนทนาเริ่มพร้อม plugin แต่ข้อความของคุณยังไม่ถึง ถ้ารายการว่างเปล่า แปลว่า plugin ไม่ได้ส่งอะไรเลย (บทสนทนาเก่า หรือ plugin ไม่ได้เปิดใช้)

## 6. อ่านฉากยังไง

### ตัวละคร

| ตัวละคร | ทำอะไร | tool ของ Claude Code ที่เกี่ยวข้อง |
|---|---|---|
| **SA** (ผู้สอดแนม) | อ่าน ค้นหา สืบค้น | `Read`, `Grep`, `Glob`, `LS`, ค้น/ดึงเว็บ, tool ของ MCP และ subagent ที่ประเภทดูเป็นการสำรวจหรือวางแผน |
| **Dev** (นักพัฒนา) | เปลี่ยนแปลงสิ่งต่างๆ | `Edit`, `Write`, `NotebookEdit`, คำสั่ง shell ที่ไม่ใช่การเทสต์ และ subagent ทั่วไป |
| **Tester** | ตรวจสอบ | คำสั่ง shell ที่ดูเป็นการรัน test, build, lint หรือ type-check และ subagent ประเภทรีวิว |
| **Summary** | เขียนคำตอบ | ปรากฏเมื่อรอบจบ |

tool ที่ไม่มีตัวละครประจำ (เช่น การอัปเดตรายการสิ่งที่ต้องทำ) จะถูกข้าม ระหว่างที่ Claude กำลังคิดระหว่าง tool จะไม่มีใคร "ยุ่ง" SA จึงขึ้น **Thinking** เพื่อให้ฉากไม่ดูนิ่ง

### หัวหน้าทีม

หัวหน้ายืนข้างกระดานงาน ทุกครั้งที่มีคนได้งานใหม่ หัวหน้าเดินไปหา ยื่นม้วนคำสั่ง และกรอบคำพูดบอกว่างานคืออะไรพร้อมรายละเอียดสั้นๆ (ชื่อไฟล์ คำสั่ง pattern ที่ค้น) ถ้ามี event เข้ามาเร็วกว่าที่หัวหน้าเดินทัน หัวหน้าเก็บไว้สามงานล่าสุดและข้ามงานเก่า เป็นการออกแบบ: สีและจอยังแสดงสถานะจริงเสมอ หัวหน้าเป็นแค่ผู้เล่าเรื่อง

### แผงต่างๆ

- **แถบบน**: pipeline SA → Dev → Tester → Summary พร้อมสถานะของแต่ละคน
- **จอ/ป้ายบนผนัง**เหนือแต่ละคน: tool และรายละเอียดปัจจุบัน
- **กระดานงาน**บนผนัง: ทั้งสี่คนพร้อมป้ายสถานะ
- **Elapsed**: เวลาตั้งแต่กด Enter ของพรอมต์ปัจจุบัน หยุดเมื่อ Claude ตอบเสร็จ
- **Tokens in / out**: สำหรับ*งานปัจจุบันเท่านั้น* "in" คือ input ใหม่บวก token ที่เขียนแคช "out" คือคำตอบ วางเมาส์บนตัวเลขเพื่อดูรายละเอียดรวมการอ่านแคช แสดง `—` จนกว่า Claude จะตอบเสร็จอย่างน้อยหนึ่งข้อความ หรือถ้าอ่านตัวเลขไม่ได้
- **Reset** ล้างภาพ ไม่กระทบ Claude Code

### การควบคุม

- กล่อง **Theme** (มุมจอ): ห้องโถงซามูไร ออฟฟิศ หรือเถียงนาอีสานยุคเก่า ค่าที่เลือกจะถูกจำไว้ในเบราว์เซอร์
- กล่อง **Session** (ปรากฏเมื่อมีบทสนทนา Claude Code เปิดอยู่ตั้งแต่สองอันขึ้นไป): เลือกว่าจะดูอันไหน บทสนทนาไม่ปนกัน "Latest" ตามอันที่ขยับล่าสุด
- **ลาก**เพื่อหมุนกล้อง **เลื่อนล้อ**เพื่อซูม **ดับเบิลคลิก**เพื่อรีเซ็ตมุม

## 7. ความเป็นส่วนตัวและความปลอดภัย

**สรุปประโยคเดียว:** ทุกอย่างอยู่ในคอมพิวเตอร์ของคุณ plugin ดูอย่างเดียว และไม่ส่งพรอมต์หรือเนื้อหาไฟล์ของคุณไปที่ไหนเลย แม้แต่ไปที่ server ของมันเอง

### ส่งอะไรไปที่ไหน

```
Claude Code ──(hook บนเครื่องคุณ)──► เว็บเซิร์ฟเวอร์ในเครื่อง ──► เบราว์เซอร์ของคุณ
                                      127.0.0.1 เท่านั้น
```

ไม่มีการส่งข้อมูลทางเครือข่ายไปยังที่อยู่อื่นเลย

### hook ส่งต่ออะไรบ้าง (และไม่มีอย่างอื่น)

- ชื่อเหตุการณ์ (เช่น "tool เริ่มทำงาน")
- รหัสบทสนทนา โฟลเดอร์ทำงาน และพาธของไฟล์บันทึกของ Claude เอง
- ชื่อ tool และประเภท agent
- ฟิลด์สั้นๆ ของ tool input: คำสั่ง shell พาธไฟล์ pattern ที่ค้น ที่อยู่เว็บ หรือคำค้น

แต่ละข้อความถูกตัดที่ 300 ตัวอักษรก่อนออกจาก hook และ server เก็บแบบสั้นกว่านั้น: พาธไฟล์เหลือแค่สองส่วนท้าย คำสั่งเหลือ 120 ตัวอักษรแรก

### ที่ไม่ถูกส่งต่อและไม่ถูกเก็บเลย

- **พรอมต์ของคุณ**
- **เนื้อหาของไฟล์**ที่ Claude อ่านหรือเขียน
- **ผลลัพธ์ของ tool**
- คำตอบของ Claude

ตรวจสอบเองได้: hook เป็นไฟล์สั้นๆ ไฟล์เดียว [`scripts/hook.mjs`](scripts/hook.mjs) ฝั่ง server มีเทสต์อัตโนมัติที่จะล้มถ้าพรอมต์หรือเนื้อหาไฟล์หลุดเข้าไปในสถานะที่เก็บ

### สิ่งที่ควรรู้

- หน้าจอแสดงคำสั่งและชื่อไฟล์ อย่าเปิดทิ้งไว้บนจอที่แชร์หรือการอัดหน้าจอ ถ้าเรื่องนี้สำคัญสำหรับคุณ
- server รับฟังเฉพาะ `127.0.0.1` อุปกรณ์อื่นในเครือข่ายเข้าไม่ได้ แต่**บัญชีผู้ใช้อื่นบนคอมพิวเตอร์เครื่องเดียวกัน**เข้าได้ ถ้าใช้เครื่องร่วมกัน ให้ถือว่าฉากนี้ผู้ใช้อื่นอาจเห็น
- เว็บไซต์อื่นในเบราว์เซอร์อ่านหรือส่งข้อมูลเข้า server นี้ไม่ได้: server ปฏิเสธคำขอจากเว็บอื่นและชื่อโฮสต์อื่น
- เพื่อนับ token server อ่านไฟล์บันทึกของ Claude สำหรับบทสนทนานั้น และเฉพาะเมื่อไฟล์อยู่ในโฟลเดอร์ Claude ของคุณ มันแยกวิเคราะห์ทุกบรรทัดแต่เก็บไว้เฉพาะตัวเลขการใช้งาน
- มีโปรแกรมเบื้องหลังเพิ่มหนึ่งตัว (Node.js) ที่หยุดเองเมื่อไม่มีกิจกรรมและไม่มีหน้าเปิดอยู่นาน 1 ชั่วโมง
- การติดตั้ง plugin คือการรันโค้ดของคนอื่นบนเครื่องคุณ โค้ดนี้สั้นและเปิดให้อ่านได้ เป็นการตัดสินใจเรื่องความไว้ใจแบบเดียวกับ plugin ทุกตัว

### เก็บอะไรลงดิสก์

โฟลเดอร์เดียว `~/.claude-code-3d/` (บน Windows คือ `C:\Users\<ชื่อคุณ>\.claude-code-3d\`) ซึ่งมีไฟล์ `server.json` เล็กๆ (หมายเลขพอร์ตและรหัส process) ขณะ server ทำงาน ถ้าเปิดโหมด debug (ดู [แก้ปัญหา](#s8)) จะมี `hook.log` ด้วย

## 8. แก้ปัญหา

หาอาการของคุณในคอลัมน์ซ้าย

| อาการ | สาเหตุที่เป็นไปได้ | ทำอะไร |
|---|---|---|
| พิมพ์ `/plugin ...` ใน**แชท VS Code** แล้วขึ้น "/plugin isn't available in this environment" | ช่องแชทนั้นไม่มีคำสั่งนี้ | ใช้**เทอร์มินัล**ของ VS Code รัน `claude plugin ...` ([ติดตั้ง วิธี B](#s4)) หรือพิมพ์ `/plugins` |
| หน้าเว็บเปิดแต่**ไม่มีอะไรขยับ** | อยู่ในบทสนทนาที่เริ่มก่อนติดตั้ง plugin หรือรันคำสั่งในเทอร์มินัลเองแทนที่จะสั่ง Claude หรือ plugin ถูกปิดอยู่ | เริ่มบทสนทนา**ใหม่** สั่ง **Claude** ให้ทำอะไรที่ใช้ tool และเช็กว่า `claude plugin list` ขึ้น `enabled` |
| หน้าเว็บขึ้น **"เข้าถึงไม่ได้" / "refused to connect"** | server ไม่ได้รัน มันเริ่มเมื่อบทสนทนา Claude Code เริ่ม (และเมื่อรันคำสั่งเปิดหน้า) | เริ่มบทสนทนา Claude ใหม่ ส่งข้อความ แล้วรีเฟรช เช็กว่า `node --version` เป็น 18 ขึ้นไป หรือรันโปรแกรมเปิดหน้าเอง: `node ~/.claude/plugins/cache/claude-code-3d/claude-code-3d/<เวอร์ชัน>/scripts/open.mjs` |
| `http://127.0.0.1:3737/debug/events` แสดง `[]` หลังส่งข้อความ | plugin ไม่ได้ส่ง event | แก้เหมือน "ไม่มีอะไรขยับ" แล้วลองโหมด debug ด้านล่าง |
| **พอร์ต 3737 ไม่ว่าง** (มีโปรแกรมอื่นใช้อยู่) | server เลือกพอร์ตว่างเอง | เปิด `~/.claude-code-3d/server.json` อ่านเลข `port` แล้วใช้ `http://127.0.0.1:<พอร์ต>/` คำสั่งเปิดหน้าจะพิมพ์ที่อยู่ที่ถูกต้องให้ด้วย |
| ฉาก**ดำหรือว่างเปล่า** | WebGL ปิดอยู่ หรือหน้ากำลังโหลด (โหลดครั้งแรกใช้เวลาหนึ่งถึงสองวินาที) | รอสักครู่ ลองเบราว์เซอร์อื่น เปิด hardware acceleration ในการตั้งค่าเบราว์เซอร์ |
| **Token ขึ้น `—`** | Claude ยังตอบไม่เสร็จสักข้อความ หรือไม่รู้จักรูปแบบไฟล์บันทึก | รอให้คำตอบแรกจบ plugin ไม่พังเพราะเรื่องนี้ แค่แสดง `—` |
| ตัวละครดู**ค้างที่ "Working"** | รอบถูกขัดจังหวะก่อนที่ tool จะรายงานกลับ | จะหายเมื่อรอบจบ หรือหลังไม่มี event สิบนาที |
| หัวหน้าดู**ตามหลัง** | การเดินใช้เวลา ส่วน tool มักเร็วกว่า | ปกติ แผงและสียังเป็นปัจจุบันเสมอ |
| ฉาก**กระตุก**บนเครื่องเก่า | ฉาก 3D ละเอียด ธีมเถียงนาละเอียดที่สุด | สลับเป็นธีม**ออฟฟิศ** ปิดแท็บอื่น หรือย่อหน้าลง |
| **"No such command" / หา `claude` ไม่เจอ** | คำสั่งของ Claude Code ไม่อยู่ใน PATH | เปิดเทอร์มินัลใหม่ หรือทำตามเอกสารติดตั้ง Claude Code เพื่อเพิ่มเข้า PATH |
| อัปเดตแล้วดูเหมือนไม่เปลี่ยน | ต้องเริ่มบทสนทนา Claude ใหม่ | รัน `claude plugin update claude-code-3d@claude-code-3d` แล้วเริ่มบทสนทนาใหม่ |
| Windows ถามว่าจะให้ **Node.js** ใช้เครือข่ายไหม | server คุยกับเครื่องคุณเองเท่านั้น | เลือกตัวเลือกที่เข้มงวดที่สุดได้ การรับส่งกับ `127.0.0.1` ปกติไม่ได้รับผลกระทบ |

### โหมด debug (แสดงข้อผิดพลาดของ hook)

ตั้งตัวแปรสภาพแวดล้อม `C3D_DEBUG=1` ก่อนเปิด Claude Code ข้อผิดพลาดจะถูกเขียนลง `~/.claude-code-3d/hook.log`

- Windows (PowerShell): `$env:C3D_DEBUG = "1"` แล้วเปิด Claude Code จากหน้าต่างเดียวกัน
- macOS / Linux: `C3D_DEBUG=1 claude`

### ยังไม่หาย?

เปิด issue ในรีโปนี้ กรุณาแนบระบบปฏิบัติการ `claude --version` `node --version` ผลของ `claude plugin list` และสิ่งที่ `http://127.0.0.1:3737/debug/events` แสดง (รายการนั้นมีแต่ชื่อ event จึงแชร์ได้อย่างปลอดภัย)

## 9. อัปเดต ปิดชั่วคราว ถอนการติดตั้ง

| ต้องการ | รัน |
|---|---|
| **อัปเดต**เป็นเวอร์ชันล่าสุด | `claude plugin marketplace update claude-code-3d` แล้ว `claude plugin update claude-code-3d@claude-code-3d` แล้วเริ่มบทสนทนาใหม่ |
| **ปิดชั่วคราว** (ยังติดตั้งอยู่) | `claude plugin disable claude-code-3d@claude-code-3d` (เปิดกลับด้วย `enable`) |
| **ถอนการติดตั้ง** | `claude plugin uninstall claude-code-3d@claude-code-3d` |
| ลบ **marketplace** ด้วย | `claude plugin marketplace remove claude-code-3d` |
| ลบ**โฟลเดอร์ที่เหลือ** | ลบ `~/.claude-code-3d` (บน Windows คือ `C:\Users\<ชื่อคุณ>\.claude-code-3d`) |
| **หยุด server ทันที** | จบ process ที่มีรหัสอยู่ใน `~/.claude-code-3d/server.json` มันหยุดเองหลังไม่มีกิจกรรมและไม่มีหน้าเปิดอยู่ 1 ชั่วโมงด้วย |

หลังถอนการติดตั้ง hooks จะหยุดทำงานตั้งแต่ต้นบทสนทนาถัดไป

## 10. คำถามที่พบบ่อย

**ทำให้ Claude Code ช้าลงไหม?**
ไม่ hooks ทำงานเบื้องหลังและจบด้วยความสำเร็จเสมอ จึงไม่ขวางหรือทำให้บทสนทนาพัง แต่ละ hook เริ่ม process Node.js สั้นๆ ซึ่งใช้ CPU เล็กน้อย plugin เพิ่ม context ราว 30 token ต่อบทสนทนา (คำสั่ง `claude plugin details` ของ Claude Code รายงานตัวเลขนี้)

**เสียเงินหรือกินโควตา Claude ไหม?**
ไม่มีการเรียก API ผลต่อโควตามีเพียงราว 30 token ที่กล่าวไปข้างต้น

**โค้ดหรือแชทของฉันออกจากเครื่องไหม?**
ไม่ ดู [ความเป็นส่วนตัวและความปลอดภัย](#s7)

**สั่งหรืออนุมัติแทน Claude ได้ไหม?**
ไม่ได้ เป็นมุมมองแบบดูอย่างเดียว

**คนในไวไฟเดียวกันเห็นฉากฉันไหม?**
ไม่ เพราะรับฟังเฉพาะ `127.0.0.1`

**ใช้กับส่วนขยาย Claude Code ใน VS Code ได้ไหม?**
ได้ ด้วยวิธีติดตั้งใน [หัวข้อ 4 วิธี B](#s4)

**ใช้กับ Claude บนเว็บหรือแอปแชทบนเดสก์ท็อปได้ไหม?**
ไม่ได้ hooks เป็นของ Claude Code ที่รันบนเครื่องคุณ ตามเอกสาร Claude Code เซสชันบนคลาวด์ไม่โหลด plugin ที่ติดตั้งในเครื่อง

**รันหลายบทสนทนาพร้อมกันได้ไหม?**
ได้ ใช้กล่อง **Session** เลือกว่าจะดูอันไหน

**"งาน" ของตัวจับเวลาและ token หมายถึงอะไร?**
หนึ่งงานคือหนึ่งพรอมต์ที่คุณส่ง ตั้งแต่กด Enter จนกว่า Claude จะจบรอบนั้น

**ทำไมกรอบคำพูดเป็นภาษาไทย?**
โปรเจกต์นี้ทำในประเทศไทย ชื่อ tool และชื่อไฟล์ใต้กรอบเป็นภาษาอังกฤษ การแปลกรอบคำพูดเป็นงานเล็ก: อยู่ในตาราง `PHRASES` ต้นไฟล์ของแต่ละธีมใน `packages/core/public/` ยินดีรับการร่วมสร้าง

**ทำธีมของตัวเองได้ไหม?**
ได้ ดู [พัฒนาต่อและร่วมสร้าง](#s13)

## 11. สำหรับ AI: วิธีติดตั้งให้ผู้ใช้

*หัวข้อนี้เขียนให้ AI (เช่น Claude Code) ที่มีคนสั่งให้อ่านรีโปนี้แล้วติดตั้ง plugin ให้ ผู้ใช้ที่เป็นคนข้ามได้ (ฉบับอังกฤษ [README.md](README.md) คือฉบับอ้างอิง)*

ทำตามขั้นตอนตามลำดับ ถ้าขั้นไหนล้มเหลวให้หยุดและบอกผู้ใช้ ห้ามอ้อมหรือแก้ไขเอาเอง

**ขั้น 0: ขอความยินยอม** บอกผู้ใช้สั้นๆ หนึ่งถึงสองประโยคว่ากำลังจะติดตั้งอะไร: plugin ของ Claude Code ที่เพิ่ม hooks ซึ่งทำงานในทุกบทสนทนา Claude Code ของเขา และส่งคำอธิบายแบบย่อของกิจกรรม tool ไปยังเว็บเซิร์ฟเวอร์เล็กๆ ในเครื่อง (127.0.0.1 เท่านั้น) มันไม่ส่งพรอมต์หรือเนื้อหาไฟล์เลย ให้ถามก่อนดำเนินการ เพราะมันเปลี่ยนการตั้งค่า Claude Code ของเขา ข้อเท็จจริงอยู่ใน [หัวข้อ 7](#s7)

**ขั้น 1: ดูว่าเขาใช้อะไร** ถามหรือตรวจ: ระบบปฏิบัติการ และเขาใช้เครื่องมือเทอร์มินัลของ Claude Code หรือส่วนขยายในตัวแก้ไขเช่น VS Code ถ้าคุณรันอยู่ในแชทของส่วนขยาย VS Code ให้ทราบว่าคำสั่ง `/plugin` **ใช้ไม่ได้ในนั้น** ให้ใช้เครื่องมือ Bash ของคุณรันคำสั่ง `claude plugin ...` แทน

**ขั้น 2: ตรวจสิ่งที่ต้องมี** โดยรันคำสั่งเหล่านี้และอ่านผลลัพธ์:

```
claude --version
node --version
git --version
```

Node.js ต้องเป็นเวอร์ชัน 18 ขึ้นไป ถ้าขาดอะไร ให้บอกผู้ใช้วิธีติดตั้ง (Node.js: https://nodejs.org, git: https://git-scm.com) **ห้ามติดตั้งซอฟต์แวร์ระบบหรือเปลี่ยนการตั้งค่าระบบโดยไม่ถามก่อน**

**ขั้น 3: ติดตั้ง** รันสองคำสั่งนี้ ใช้ขอบเขต `user` ตามค่าเริ่มต้น เว้นแต่ผู้ใช้ขอ `--scope project` หรือ `--scope local`

```
claude plugin marketplace add thekaroe-thailand/claude-code-3d
claude plugin install claude-code-3d@claude-code-3d
```

**ขั้น 4: ตรวจว่าติดตั้งแล้ว**

```
claude plugin list
```

ควรเห็นรายการ `claude-code-3d@claude-code-3d` ที่มี `Status: enabled` ถ้าขั้นเพิ่ม marketplace ล้มเหลว ให้แสดงข้อผิดพลาดแก่ผู้ใช้ และเช็กว่า `git --version` ใช้ได้และเข้าถึง https://github.com ได้

**ขั้น 5: บอกผู้ใช้ว่าต้องทำอะไรต่อ** plugin โหลดตอนบทสนทนาเริ่ม ดังนั้นมันจะไม่ทำงานในบทสนทนาที่คุณติดตั้งให้ บอกให้เขาเริ่มบทสนทนา**ใหม่** (ใน VS Code: รัน "Developer: Reload Window" จาก command palette แล้วเปิดแชทใหม่) จากนั้นให้ข้อทดสอบจาก [หัวข้อ 5](#s5) และที่อยู่ `http://127.0.0.1:3737/`

**ขั้น 6: ตรวจเพิ่มเติม (ไม่บังคับ) เฉพาะในบทสนทนาใหม่ที่ส่งข้อความไปแล้ว**

```
curl -s http://127.0.0.1:3737/health
curl -s http://127.0.0.1:3737/debug/events
```

คำสั่งแรกควรได้ JSON ที่มี `"name":"claude-code-3d"` คำสั่งที่สองแสดงรายชื่อ event ที่ได้รับ ถ้า server ไม่ตอบ ให้อ่าน [แก้ปัญหา](#s8)

**ห้าม:**

- แก้ `settings.json` หรือไฟล์ตั้งค่า Claude Code ใดๆ ด้วยมือ คำสั่ง `claude plugin` ทำหน้าที่นั้นอยู่แล้ว
- รันอะไรด้วยสิทธิ์ผู้ดูแลระบบหรือ `sudo`
- เปิดพอร์ตไฟร์วอลล์ หรือทำให้ server รับฟังที่อื่นนอกจาก `127.0.0.1`
- ขอหรือจัดการบัญชี API key หรือ token ไม่ต้องใช้อะไรเหล่านี้
- พิมพ์คำสั่งติดตั้งลงในแชทของผู้ใช้เหมือนเป็น slash command ในส่วนขยาย VS Code

**ถอนการติดตั้งภายหลัง:** `claude plugin uninstall claude-code-3d@claude-code-3d` แล้วลบโฟลเดอร์ `~/.claude-code-3d`

**ถ้าอยากตรวจโค้ดก่อนติดตั้ง** (แนะนำ โค้ดสั้น) ไฟล์ที่สำคัญคือ:

| ไฟล์ | ทำอะไร |
|---|---|
| `hooks/hooks.json` | ลงทะเบียน hooks ทั้งหมดรันแบบ async ผ่าน `node` |
| `scripts/hook.mjs` | โปรแกรม hook ตัดทอนเหตุการณ์แล้วส่งไป `127.0.0.1` จบด้วย exit 0 เสมอ |
| `scripts/lib.mjs`, `scripts/open.mjs` | หาหรือเริ่ม server ในเครื่อง และเปิดหน้าเว็บ |
| `packages/core/src/server.js` | เว็บเซิร์ฟเวอร์ในเครื่อง พร้อมการตรวจ host และ origin |
| `packages/core/src/adapter.js` | แปลงข้อมูล hook เป็นเหตุการณ์ ทิ้งส่วนอื่นทั้งหมด |
| `packages/core/src/transcript.js` | อ่านเฉพาะตัวเลขการใช้ token จากในโฟลเดอร์ Claude |
| `packages/core/src/daemon.js` | รัน server เบื้องหลัง หยุดเองหลังว่าง 1 ชั่วโมง |

## 12. ทำงานยังไง

```
 Claude Code                                    your computer only
┌────────────┐  hook event   ┌────────────┐  POST /hook   ┌───────────────────┐  live stream  ┌───────────┐
│ a tool     │ ────────────► │ hook.mjs   │ ────────────► │ local server      │ ────────────► │ browser   │
│ starts or  │  (async, JSON │ trims the  │  127.0.0.1    │ (Node.js)         │ (SSE)         │ 3D scene  │
│ ends, turn │   on stdin)   │ event      │               │ keeps the state   │               │ (three.js)│
│ ends       │               └────────────┘               │ reads token usage │               └───────────┘
└────────────┘                                            └───────────────────┘
        │  transcript file (usage numbers only)  ▲
        └────────────────────────────────────────┘
```

อ่านจากซ้ายไปขวา: Claude Code ส่งเหตุการณ์ให้โปรแกรม hook ซึ่งตัดทอนแล้วส่งไปยังเซิร์ฟเวอร์ในเครื่อง จากนั้นเซิร์ฟเวอร์ส่งสถานะสดไปให้เบราว์เซอร์ที่วาดฉาก เซิร์ฟเวอร์ยังอ่านตัวเลขการใช้ token จากไฟล์บันทึกของ Claude ด้วย (ลูกศรด้านล่าง)

1. **Hooks** `hooks/hooks.json` ลงทะเบียนโปรแกรม hook สำหรับ `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `SubagentStop` และ `Stop` ทั้งหมดเป็นแบบ asynchronous
2. **การเริ่ม server** ครั้งแรกที่ hook ทำงานแล้วไม่พบ server มันจะเริ่ม server เบื้องหลัง (`packages/core/src/daemon.js`) และบันทึกพอร์ตไว้ใน `~/.claude-code-3d/server.json` server ตัวเดียวใช้ร่วมกันทุกบทสนทนา ใช้พอร์ต 3737 ก่อน ถ้าไม่ว่างจะใช้พอร์ตว่างอื่น
3. **สถานะ** server เก็บสถานะเล็กๆ หนึ่งก้อนต่อหนึ่งบทสนทนา: ใครกำลังยุ่งกับ tool อะไร งานเริ่มและจบเมื่อไร และยอด token พรอมต์ใหม่เริ่มงานใหม่ของบทสนทนานั้น
4. **หน้าเว็บ** เบราว์เซอร์เปิดสตรีมสด (server-sent events) แล้ววาดฉากใหม่ทุกครั้งที่สถานะเปลี่ยน การเดินของหัวหน้าเป็นแอนิเมชันที่สร้างจากการเปลี่ยนสถานะในเบราว์เซอร์
5. **Token** server อ่านไฟล์บันทึกของ Claude สำหรับบทสนทนานั้นแล้วบวกตัวเลขการใช้งาน โดยนับแต่ละข้อความครั้งเดียว (หนึ่งข้อความอาจปรากฏหลายครั้งในไฟล์) ยอดของงานคือผลต่างจากยอดรวม ณ ตอนที่ส่งพรอมต์
6. **ตาข่ายนิรภัย** บทบาทที่ค้าง "working" สิบนาทีโดยไม่มี event จะถูกปล่อย บทสนทนาเก่าที่เกินสิบสองอันล่าสุดจะถูกทิ้ง server หยุดเองหลังไม่มี event และไม่มีหน้าเปิดอยู่ 1 ชั่วโมง

รายละเอียดการจับคู่อยู่ใน `packages/core/src/rules.js` การจัดการ event อยู่ใน `packages/core/src/state.js`

## 13. พัฒนาต่อและร่วมสร้าง

```
git clone https://github.com/thekaroe-thailand/claude-code-3d.git
cd claude-code-3d/packages/core
npm test            # เทสต์หน่วยและเทสต์รวม (ตัวรันเทสต์ในตัวของ Node)
npm run demo        # เซสชันปลอมที่เล่นวนซ้ำที่ http://127.0.0.1:3737/
```

จากโฟลเดอร์รากของรีโป:

```
claude --plugin-dir .              # โหลด plugin จากโฟลเดอร์นี้สำหรับหนึ่งเซสชัน
claude plugin validate .           # ตรวจไฟล์ marketplace
claude plugin validate .claude-plugin/plugin.json
```

โครงสร้าง:

```
.claude-plugin/     ไฟล์ manifest ของ plugin และ marketplace
hooks/hooks.json    การลงทะเบียน hook (ทั้งหมดเป็น asynchronous)
commands/office.md  คำสั่ง /claude-code-3d:office
scripts/            โปรแกรม hook โปรแกรมเปิดหน้า ตัวช่วยร่วม
packages/core/
  src/              server, adapter, state machine, ตัวอ่าน transcript, daemon
  public/           หน้าเว็บ สามธีม และ vendor/ (สำเนา three.js)
  test/             เทสต์อัตโนมัติ
docs/images/        ภาพหน้าจอที่ใช้ใน README นี้
```

- **ผู้ใช้ไม่ต้องติดตั้งอะไรเพิ่ม** ไฟล์ three.js ไม่กี่ไฟล์ที่ฉากใช้ถูกเก็บไว้ใน `packages/core/public/vendor/` หลังเปลี่ยนเวอร์ชัน three.js ให้รัน `npm install` และ `npm run vendor` ใน `packages/core`
- **เพิ่มธีม** เขียนโมดูลฉากใน `packages/core/public/` (คัดลอกธีมที่มีอยู่ เช่น `app.office.js` เป็นจุดเริ่ม) เพิ่มหนึ่งบรรทัดในรายการใน `packages/core/public/themes.js` และจะเพิ่มบล็อก `[data-theme="รหัสธีม"]` ใน `style.css` สำหรับหน้าตาของกรอบหน้าเว็บด้วยก็ได้ กล่องเลือกธีมและกล่องเลือก session จะปรากฏเอง
- **ปล่อยการเปลี่ยนแปลง** เพิ่มเลข `version` ใน `.claude-plugin/plugin.json` และ `.claude-plugin/marketplace.json` รันเทสต์และคำสั่ง validate ทั้งสอง commit และ push ผู้ใช้ได้รับด้วย `claude plugin marketplace update` และ `claude plugin update`
- **เทสต์** ครอบคลุมการจับคู่บทบาท การตัดทอนข้อมูลส่วนตัวฝั่ง server การนับ token (รวมข้อความซ้ำ) การตรวจ host และ origin และความปลอดภัยของพาธ กรุณาเพิ่มเทสต์เมื่อแก้บั๊ก

ยินดีรับรายงานบั๊กและ pull request กรุณาอย่าวางข้อมูลส่วนตัวใน issue

## 14. ข้อจำกัดที่รู้อยู่

- ทดสอบบน Windows 11 กับเครื่องมือเทอร์มินัลของ Claude Code (เวอร์ชัน 2.1.269) และส่วนขยาย Claude Code สำหรับ VS Code ในเบราว์เซอร์ Chrome และ Edge ยังไม่ได้ทดสอบบน macOS และ Linux
- Claude Code มีเอกสารว่า hooks ส่งอะไรมา แต่ระบุว่ารูปแบบไฟล์บันทึกของมันเป็นของภายในและอาจเปลี่ยน การนับ token เขียนแบบป้องกันและแสดง `—` ถ้ารูปแบบเปลี่ยน แต่ตัวเลขอาจผิดโดยไม่มีใครรู้จนกว่าจะมีการตรวจสอบ
- ไม่มีอะไรรายงานจังหวะที่ Claude กำลังคิดหรือเขียน "Thinking" จึงเป็นการอนุมาน: แสดงเมื่อรอบกำลังทำงานและไม่มี tool ไหนยุ่งอยู่
- subagent ถูกจับคู่กับสี่ตัวละครจากคำในประเภทหรือคำอธิบาย ประเภทที่ไม่รู้จักไปที่ Dev
- ฉากเป็นการตีความ ตัวละครเป็นอุปมา ไม่ได้ตรงกับเอเจนต์ AI แยกกัน
- กรอบคำพูดเป็นภาษาไทย
- หน้าเว็บและ plugin ดูได้เฉพาะบทสนทนาที่เริ่มหลังติดตั้งและเปิดใช้ plugin
